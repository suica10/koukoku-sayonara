# 設計メモ（2026-11-20）

## なぜ国内で成立しうるか
- 日本は AD ブロックの認知度・利用率が海外より低い
  → 広告前提のモデルも、広告を消すモデルも、海外より長く効く
- 海外サービスはあるが日本語のサポート・国内広告事情への最適化がない
- 名前は小林製薬式に「機能そのまま」: 広告さよなら（仮）

## サーバー側
- AdGuard Home を A1 (jp-browser-1) の 127.0.0.1:3053 で動かす
- 上流は Cloudflare / Google の DoH
- フィルタ更新は AdGuard Home の自動更新に任せる
- ログは最小限（クエリログはプライバシー配慮で短期間のみ／無効も検討）

## 公開方法
- DoH のみ。URL パスにユーザートークンを含める（例: https://dns.example.jp/dns-query/<token>）
- UDP/TCP 53 は公開しない
- 濫用対策: トークン単位のレート制限、漏れたトークンの失効

## アプリ側（将来）
- ボタン2つ: 課金 / DNS 登録（構成プロファイル導入 or Android Private DNS 設定）
- 設定変更はサーバー側で完結させ、アプリは更新しない設計
