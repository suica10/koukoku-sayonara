# 広告さよなら（仮称）

国内向け DNS 広告フィルタサービス。海外には AdGuard DNS / NextDNS のような
DNS レベルで広告・トラッキングを止めるサービスがあるが、国内事業者はいない、という隙間。

## コンセプト
- DNS（DoH）で名前解決の段階で広告・トラッキングドメインを遮断する
  → ブラウザだけでなくアプリ内広告にも効く
- 公開リゾルバにはしない。ユーザーごとのトークン付き DoH URL で提供する
  （オープンリゾルバは DNS 増幅攻撃の踏み台になるため）
- クライアントアプリは「課金ボタン」と「DNS 登録ボタン」だけの薄い器。
  価値はサーバー側のフィルタリストと名前解決にある
- 基盤は Oracle Cloud A1（jp-browser-1）。DNS は軽いので十分回る

## 構成
- AdGuard Home（リゾルバ＋フィルタ）を A1 の localhost で稼働
- DoH はリバースプロキシ経由で公開（トークンでユーザー識別）
- フィルタ: 公開リストを初期採用する
  - AdGuard DNS filter
  - OISD (small)
  - 280blocker（国内向けリスト）
  ※ 商用化前に各リストのライセンスを確認すること

## ロードマップ
1. A1 にプロトタイプを立てる（自分用に使って効き目を検証）
2. iPhone 用 DoH 構成プロファイルの自動生成
3. 課金（自前 Web 課金）と登録フロー
4. アプリ（課金ボタン＋DNS 登録ボタン）
